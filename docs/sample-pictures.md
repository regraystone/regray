# Pictures for the Inquire page's table questions

All the table pictures are Regray's own photos, kept under `storage/app/public/question-choices/` like the catalogue photographs (committed, random names; `database/seeders/data/detail_fields.php` names each one's choice) and sent to the public bucket with `scripts/upload-catalog-images.sh`. Each was scaled to at most 1200 px with its metadata stripped. The table shapes are 1200 x 900: their wide photos were extended to the picture cards' 4:3 with their own background above and below, so no card crops the table. A choice with no picture shows an icon; the Choices page under Services replaces or adds one.

- **Table shape**: Rectangular, Round, Oval, Square, Rounded Rectangle, Organic / Freeform.
- **Center table base design**: Sphere Accent Pedestal, U-Base, Half Moon.
- **Side table base design**: C-Legs V1, C-Legs V2, Cylindrical Pedestal, Hourglass V2.
- **Dining table base design**: Diamond, Close Cage, Tubular V1, Tubular V2, X-Base V1, X-Base V2, Clover V1, Clover V2, Y-Base, Hourglass V1.
